# Documentation revision

The October 14 revision rewrites the project documentation in English according to version 4.0 of the writing guide. Existing documents are updated in place. The documentation index links to these files, without a second set of reading copies.

Independent editorial review covered 313 research documents. The revision preserves numerical results, equations, parameter ranges, and the distinction between complete certificates and incomplete recovered records. Raw code, data, and numerical certificates are unchanged. Historical hashes of edited prose identify older versions and are not checksums for the current documentation.

One counting typo is corrected: an 8 by 4 bilayer has 32 rung edges and 64 rung-plane neighbor edges. No numerical inputs changed. Mathematical delimiters were normalized for GitHub Markdown. External hyperlinks were replaced with plain bibliographic references. No new spectral-gap result is claimed.
