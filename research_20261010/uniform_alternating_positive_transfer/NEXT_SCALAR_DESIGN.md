# Scoped next scalar-design options

No additional computation is authorized or requested by this note. The following options need only the already accepted physical data, but any positive outcome needs new directed scalar certification and review.

1. Optimize rational eta radii separately for a few specified physical-gap targets, using the new positive-window lemma and the existing n30/n32/n34 seeds. The final chosen tests favor n32 for width. This is a finite comparison, not proof that n32 is globally optimal. The main loss is in the seed thermal endpoint: log S loses2A, log T loses8A, and log(S^2T) loses12A. The T^2 factor in the next thermal update further amplifies that loss. The resulting bootstrap basin/late thermal window generally limits width before the finite bridge does. At the .02 target, the current short-cell Weyl bridge is close enough that replacing it with certified finite-purity transport can matter.

2. Retain the exact cosh comparison, already proved in the accepted finite-trace argument, instead of exp(x^2/2). It gives S>=S0/cosh((3/2)beta n r)^2 and T>=T0/cosh(3beta n r)^2. This is a modest but strictly sharper scalar bound, needs no new physical input, and preserves all old intervals. Sharpening the seed with the actual negative MPS energy rather than its sign is another inexpensive candidate: the accepted own-length energy supplies an explicit numerator lower weight and can strengthen the dominant-atom forcing threshold.

3. The compulsory temperature rescaling is beta_actual=beta0/c; it preserves the existing normalized thermal input and exact MPS expectation cancellation. An ADDITIONAL cooling factor q is a different optimization. It incurs a q^2 cost in A while potentially improving the uniform thermal endpoint. Existing accepted Gibbs-cooling/character-projection machinery can construct safe cooled seed bounds from the unchanged I/P data and own MPS anchors. The spatial history operator at q beta0 is NOT X_beta0^q, and its eigenvalues/moments must not simply be powered. Every physical seam must be cooled as a physical Gibbs trace before valid character projection, support, and tail bounds are reconstructed. Generic two-sector cooling is known to lose signed-moment information even at q=1, so improvement is possible to test but not established. Required inputs are exactly the eighteen beta49/4 I/P intervals, signed-sector support/majorant certificate, own MPS60/64/68 energy quotients, and the already reviewed cooling/character-projection lemmas.

4. Prebootstrapped saved uniform starts improve purity but increase the finite comparison cost: doubling both physical length and normalized beta multiplies A by16. The original n30/n32/n34 starts are now all eligible because positive cell transfer removes their old parity restriction. Try those before larger joint-doubling starts. No new physical anchors are needed for an already certified scalar state, but its exact length, temperature, S and T must be retained.

5. If a larger target/radius makes the short Weyl bridge restrictive, use the accepted uniform finite purities with C_L -> C_L exp[-(9/4)(beta0 L r)^2]. Preserve each source's actual numerator provenance, especially physical24's parity/MPS48 construction. This changes the short bridge only; it cannot repair a failed large-size bootstrap seed.

All optimization statements are limited to these sufficient recipes. Failure would not establish gaplessness, a maximal neighborhood, or a need for a larger trial space.
