## Why this establishes failure of all covered paths

For each frozen closed beta box, independently start from its J,C upper envelope. On positive arguments G is increasing. Decimal-grid outward rounding therefore gives optimistic a=G(J), b=G(C²a). If an upper iterate is nonpositive, no strictly positive certificate endpoint survives that update.

At each positive time-first pair, independently check P=a²b against99/100. Then run the accepted canonical branch from S=a sqrt(b), T=K=a²b, with its joint-aware first cycle and ordinary subsequent cycles. Every such branch reaches an exact nonpositive outward upper iterate before any accepted target entrance. Next advance the time-first branch itself with a'=G(a²b), b'=G(b²a'). That branch also reaches a nonpositive upper iterate after finitely many steps. This exhausts every allowed whole-cycle delay. A finite safety limit would return inconclusive, and is never used as a proof of failure.

Thus the argument is stronger than merely observing P<99/100 at one temperature or one delay: both closure possibilities are checked at every delay, and the remaining delay path ends. All finite windows are granted irrespective of the diagnostic direct-window value; a better bridge alone cannot repair this particular failed continuation grammar.

The fresh verifier imports only previously independently written arithmetic primitives, frozen J/C envelopes, and certified tail bounds. It does not read prior exclusion decisions or producer branch histories to decide a result. It uses decimal50-place rounding rather than the producer's dyadic160-bit rounding. No point sampling, floating scan or optimization result enters the proof.
