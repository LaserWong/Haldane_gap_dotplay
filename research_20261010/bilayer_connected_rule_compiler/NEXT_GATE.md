# Proposed correctness and performance checks

This plan was neither executed nor authorized as part of the compiler prototype.

1. Independently review the compiler, tuple coverage, local matrices, bounds, translation proof and fixture output. Verify all four pinned input seals.
2. Use the physical Cartesian edge matrix from the separate independent review, or a fully exact validated conversion, to compile Cartesian rules. Check every local matrix and both known fixtures again. Only then use the 15 distinct-pair-color probe lemma.
3. Build pull indexes keyed by target occupancy mask and target color assignment. Nonvacuum embeddings should have an incidence index keyed by an occupied global target site. Canonically assign each matching embedding to its smallest occupied site in that embedding so a six-site target never double counts it. The local target occupancy mask and color digits select a small source transition list before any generic q6 lookup. Do not scan 297237 records × 32 translations × 169911 supports.
4. Vacuum records need separate treatment. Each vacuum projector is ∏_{i∈B}(1−n_i). Expand it as an exact occupation-subset polynomial. Sum the constant contribution from geometry and index the nonempty subsets by occupied sites. The vacuum projector is not itself a support-independent scalar. Combine translated identical subsets, preserve stabilizers and signs, and measure the resulting index size.
5. Connect to the accepted generic 58D q6 lookup only after confirming channel convention/permutations. The supplied accepted review seal is 13e12855678f844ce419319908087ad05a7de6d5dd547ee2060d4db7ccee1887. This prototype did not execute the lookup or import its source. Source coefficients and every intermediate image need an explicit bound and exact GMP import before any production execution.
6. Request a separately bounded sample budget. Select deterministic supports across nonzero/zero source classes, occupied-edge counts, distant clusters, wraparound and stabilizers, with explicit worst-observed transition classes. Build only required cache entries. Record candidate embedding hits, occupancy-pruned hits, color-rule hits, generic lookup calls, cache misses/hits, limb sizes, setup CPU/RSS, and exact class multiplicities. Prove absence of omitted source-zero supports in terms that require them. Sample timings alone do not establish a universal runtime bound.
7. Production remains blocked until correctness is independently accepted, total memory payload and index footprint are measured, and a conservative resource proposal including setup and all relevant contractions passes the agreed gate. Neither these counts nor the small fixtures establish 8×4 runtime feasibility or a new .11 endpoint.
