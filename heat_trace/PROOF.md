# Streamed fixed-point heat-trace enclosures

Scope: spin-1 isotropic Heisenberg Hamiltonian, bilinear coefficient one, periodic length L in {6,8,10}, with I, P, C boundary rotations theta = 0, pi, 2 pi/3. This supplies finite physical thermal inputs for Appendix A. It is not a proof of a uniform physical gap. No eigenvalues are computed or used.

## Hamiltonian and spectral interval

The Sz product basis has words w in {-1,0,1}^L. H has diagonal sum_k w[k-1] w[k]. Each allowed neighboring exchange has off-diagonal coefficient 1, except the (L-1,0) seam where it has coefficient z^(w[0]-v[0]), z=exp(i theta), for row v and column w. This is exactly the archived physical convention. The spin-1 ladder matrix elements give an exchange coefficient (sqrt(2) sqrt(2))/2=1.

Each bond is a unitary conjugate of S1.S2 and hence is at most 1. For a three-site path, h12+h23=S2.(S1+S3). The endpoint total spin a is 0,1,2. Coupling it to spin-1 gives eigenvalues [j(j+1)-a(a+1)-2]/2. The minimum is -3 (a=2,j=1). Any two twisted bonds forming a path can be gauged to untwisted bonds by on-site rotations, so the same lower bound holds for all translated three-site clusters. For L>=3 the sum of these clusters is 2H, giving -3L/2 <= H <= L. (This argument deliberately excludes the doubled L=2 bond.)

Thus P=(16-3L/2-H)/16 has spectrum in [1-5L/32,1], which is a subset of [-1,1] for 3<=L<=12. In particular ||P||_2<=1. All present runs use even L so 16-3L/2 is integral. With mu=84 and beta=21/2,

F=exp(mu(P-I))=exp[-(beta/2)(H+3L/2)].

The target thermal trace is

Z=Tr exp[-beta(H+a L)]=exp(x) ||F||_F^2,
a=700741/500000 and x=beta L(3/2-a)>0.

## Polynomial normalization and omitted tail

Let J=256, Q=2^56, S=sum_{j=0}^J mu^j/j!, b_j=(mu^j/j!)/S, and c_j=floor(Q b_j). The coefficients are generated with integer factorials, not floating-point exponentials. In particular c_j>=0 and sum c_j<=Q. Put p(P)=sum b_j P^j and q(P)=sum(c_j/Q)P^j.

Since ||P||<=1, ||p(P)-q(P)||<=257/Q. If R is the unnormalized exponential tail, then

R <= [mu^(J+1)/(J+1)!] / [1-mu/(J+2)].

Comparing both the truncated numerator and its normalization with exp(mu) gives ||F-p(P)|| <= 2R/S. The certificate generator checks, using exact rationals, that 2R/S < 1/Q. This also bounds the terms whose c_j vanish.

## Exact integer Horner and per-column error

For each selected basis column e, initialize X=0 and, descending through k=kmax,...,0, perform

X <- floor_coordinates(16 P X / 16) + c_k e.

Here kmax=172 is independently obtained from the coefficients. For real twists, each coordinate floor has error in (-1,0]. For C, use omega=z with omega^2=-1-omega and represent a vector by integer pairs u+omega v. The physical squared modulus is u^2-u v+v^2. The two floor errors are alpha, gamma in (-1,0], and

|alpha+omega gamma|^2=alpha^2-alpha gamma+gamma^2 <= 1.

This bound follows by maximizing the convex quadratic over the square's four vertices. Thus in a block of dimension d every Horner step adds a physical vector error of norm at most sqrt(d). Since ||P||<=1, the final column has

||X/Q-F e|| <= [(kmax+1) ceil(sqrt(d)) + 257 + 1]/Q = E_d/Q.

The extra first-step allowance is conservative: the actual initial floor of zero is exact. Floors divide signed integers toward negative infinity. The C++ implementation explicitly corrects C++'s signed truncating division.

## Symmetry orbits without a covariance assumption on flooring

Let R be the right shift, (Rw)[k]=w[k-1 mod L]. The magnetic translation T acts by

T|w> = z^(-w[L-1]) |Rw>.

It commutes with H. This can be checked bond by bond: R moves the seam to (0,1). The subsequent on-site rotation z^(-S0z) removes that seam phase and places it back on (L-1,0). T is a monomial unitary, so it preserves norms and maps each basis word to the cyclically shifted word up to phase.

Let B reverse the sites, (Bw)[k]=w[L-1-k], and let V reverse all spins, (Vw)[k]=-w[k]. B and V each conjugate H(z) into H(z^-1). Complex conjugation K does the same. Consequently BK and VK are norm-preserving antiunitary symmetries of H and of F (the function defining F has real coefficients). On real basis vectors, they act as reversal and spin flip. For I and P these are ordinary permutation symmetries as well.

Therefore the exact column norms ||F e_w|| are constant on the word orbits generated by cyclic shifts, reversal, and spin flip. For negative M blocks we enumerate cyclic/reversal orbits and multiply their sizes by two for the positive M partners. For M=0, spin flip is included in the orbit. Each block dimension is unchanged by these operations. Orbit weights are positive integers, and the code checks their sum is 3^L.

For every omitted word choose one exact monomial (anti)unitary mapping its representative's basis vector to that word up to phase. Apply the same map and phase adjustment to its representative's computed column. This defines an auxiliary approximate full matrix Y, whether or not the floor quantizer commutes with the symmetry. Each reconstructed column has the same error bound E_d/Q. Hence, with representative multiplicities m_r,

||Y||_F^2 = N/Q^2,   N=sum_r m_r ||X_r||^2 (an exact integer),
||Y-F||_F <= sqrt(sum_r m_r E_(d_r)^2)/Q <= e/Q,

where e is the integer ceiling of that final square root. No equality is asserted between symmetry-reconstructed quantized columns and columns obtained by independently flooring all physical words. For I the coordinate permutations do commute with floor and the integer totals are bitwise equal. For P/C small differences in integer totals are expected and are covered by this error argument. None of the original printed totals is used as an input.

## Rational thermal enclosure and acceptance

Set r=floor(sqrt(N)). Then

max(0,r-e)/Q <= ||F||_F <= (r+1+e)/Q.

Let s=sum_{j=0}^100 x^j/j!. Since x<102, the positive series gives

s <= exp(x) <= s+[x^101/101!]/[1-x/102] = u.

The stored exact rational endpoints are

Z_lo=s max(0,r-e)^2/Q^2,
Z_hi=u (r+1+e)^2/Q^2.

Acceptance requires the entire interval to lie strictly inside the archived center +/- 1/100000. Float conversions are only display values. The center is used solely as a final comparison. The physical integer N, error envelope, and interval do not depend on the printed integer totals.

## Integer range, memory, and resumption

At any Horner stage the exact polynomial column norm is at most Q, because coefficients are nonnegative and sum to at most Q. Accumulated physical rounding error is at most 257 sqrt(d). Each Eisenstein coordinate has absolute value at most twice the physical modulus. The executable uses the looser integral coordinate bound 2(Q+257d), then verifies that the maximum absolute row sum of the real two-coordinate matrix times this bound is strictly below INT64_MAX. This bounds all sparse partial sums, not only final row sums. Coefficient addition is also bounded by the same invariant.

Squared coordinate norms use signed 128-bit multiplication. At most 64 terms are accumulated into an unsigned 128-bit chunk before conversion to GMP. The same coordinate bound gives fewer than 2^123 per such chunk for all d<=3^12, so no unsigned overflow is possible. Final integer column norms and totals use arbitrary precision. The d by d matrix of columns is never stored: only sparse P, four length-d integer vectors, and orbit data.

Each completed chunk is written with fsync to a temporary JSON file and atomically renamed. Its identity includes L, twist, symmetry mode, block, column range, coefficient SHA256, and C++ source SHA256. Existing chunks are validated before being reused. An interrupted in-flight chunk can be rerun. Completed chunks are not recomputed.

## Independent checks and limits

validate_reference.py executes the archived all-column implementation in memory with only a return-total instrumentation. All three L6 I/P/C totals are bitwise equal to the new unsymmetrized streamed calculations. Symmetry identities are also checked in exact Eisenstein arithmetic by validate_symmetries.py. The argument above, rather than the small test, justifies their extension to L8/L10.

The source archive is preserved unchanged. New code, checkpoints, timing logs, and rational certificates are kept in this separate work directory.
